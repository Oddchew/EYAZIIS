## Цель

Изучить и отработать практические навыки применения методов автоматического
распознавания языка текстовых документов.

## Методы

### 1. N-грамм (Cavnar & Trenkle, 1994)

- Профиль языка / документа: частоты N-грамм длины 1…5, топ ~300.
- Метрика **Out-of-Place**: сумма \|rank_doc − rank_lang\|; отсутствующим N-граммам — штраф.
- Выбор языка с минимальным расстоянием.
- Основан на законе Ципфа.

### 2. Алфавитный

- Профиль: относительные частоты букв (включая диакритику).
- Учёт характерных французских символов (é, è, à, ç, œ…).
- Расстояние L1 между векторами частот.

### 3. Нейросетевой

- MLP: вход (частоты букв + маркеры + bigrams/trigrams) → hidden ReLU → softmax (2 класса).
- Обучение SGD, кросс-энтропия, без внешних ML-библиотек.

Итоговый ответ — **majority vote** трёх методов.

## Структура проекта

```
Lab2/
  app.py                 — FastAPI-приложение
  requirements.txt
  README.md
  models/
    preprocess.py        — HTML → text, нормализация
    ngrams.py            — N-грамм профили + Out-of-Place
    alphabet.py          — алфавитный метод
    neural.py            — MLP-классификатор
    detector.py          — единый фасад
  data/
    corpus.py            — тренировочный и тестовый корпуса
    neural_model.json    — веса MLP (после обучения)
    history.json         — история распознаваний
    uploads/             — загруженные файлы
  templates/             — Jinja2 HTML
  static/style.css
```

## Установка и запуск

```bash
cd Lab2
pip install -r requirements.txt
python app.py
# → http://localhost:8000
# из локальной сети: http://<IP>:8000
```

При старте автоматически обучаются профили N-грамм, алфавитный и MLP
на встроенном корпусе (~20–40 КБ на язык).

### API

- `GET /api/detect?text=...` — JSON-результат по трём методам
- `GET /api/status` — статус моделей
- `GET /export` — скачать JSON-отчёт (история + статистика обучения)

## Возможности интерфейса

- **Распознать** — вставка текста / загрузка HTML, сравнение трёх методов
- **Тест-коллекция** — 8 HTML-документов, точность и среднее время по методам
- **Обучение** — переобучение профилей
- **История** — последние распознавания
- **Экспорт** — сохранение результатов в JSON (для отчёта и печати)

## Требования методички (выполнено)

- Тренировочный набор 20–120 КБ на язык
- Построение профилей языков и входных документов
- Метрика расстояния / вероятности, выбор min
- Вход: HTML-документы сопоставимого размера
- Выход: язык + сводная статистика
- Сохранение в файл и печать
- Простой UI + help
