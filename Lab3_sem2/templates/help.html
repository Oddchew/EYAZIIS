Справка

Назначение

Автоматическое реферирование текстовых документов: классический реферат (набор информативных предложений) и реферат в виде ключевых слов.

Классический реферат (sentence extraction)

  1. Вычисляются веса слов документа (модифицированный TF·IDF).
  2. Для каждого предложения считаются Posd, Posp и Score.
  3. Итоговый вес: Posd × Posp × Score.
  4. Выбираются до 10 предложений с наибольшим весом в порядке текста.

Posd(S) = 1 − BD(S)/|D|, Posp(S) = 1 − BP(S)/|P|.
w(t,D) = 0.5 · (1 + tf(t,D)/tfmax(D)) · log(|DB|/df(t)).

Ключевые слова

Термины ранжируются по tf · w(t,D). Строится иерархия: короткое слово-корень и более длинные термины, содержащие этот корень (именные группы).

Тематические группы

Предложения группируются по доминирующим ключевым терминам. Это простая концептуальная структура для обзора тем документа (альтернатива отдельной базе знаний).

Запуск

pip install -r requirements.txt
python app.py
